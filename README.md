## Sobre o projeto

A **VetPerto** é uma empresa fictícia de tecnologia que conecta tutores de cães e gatos da periferia da Zona Leste de São Paulo a clínicas veterinárias populares, ONGs de proteção animal e mutirões de castração. A plataforma (app/PWA, portal web e WhatsApp) oferece agendamento, lembretes, carteira de vacinação digital e prontuário simplificado.

O trabalho integra as disciplinas do semestre:

- **Estrutura Organizacional:** missão, visão, valores e organograma funcional.
- **Inteligência Artificial:** assistente de triagem com Processamento de Linguagem Natural e sistema especialista baseado em regras (prioridades vermelho/amarelo/verde).
- **Data Analytics e Big Data:** KPIs, Data Warehouse em esquema estrela, ETL e painel de BI.
- **Gestão de Serviços e Fornecedores:** catálogo de serviços de TI, SLAs, comparação de fornecedores e plano baseado no ITIL 4.
- **Sistemas Distribuídos:** arquitetura de microsserviços com API Gateway e mensageria.
- **Estrutura Computacional:** infraestrutura híbrida (nuvem + escritório), diagrama de rede, máquina virtual de homologação (VirtualBox + Ubuntu Server + Docker + PostgreSQL) e segurança.
